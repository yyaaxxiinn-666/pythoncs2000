# pythoncs2000
Initial Python practice repository for **CS 2000: Introduction to Program Design and Implementation** at [Northeastern University](https://www.northeastern.edu/).

## Overview

This repository contains foundational coding exercises, lab work, and practice scripts completed while learning Python fundamentals in CS 2000. 

## Topics Covered

* Basic syntax, variables, and data types
* Conditional logic (`if`, `elif`, `else`) and loops (`for`, `while`)
* Functions, scope, and modular design
* Core data structures (lists, dictionaries, tuples, sets)
* File input/output and basic debugging
